# GA4 — Key Events para configurar manualmente

Estes eventos já estão preparados no código do site. A marcação como key event precisa ser feita no painel do GA4.

## Eventos recomendados como key events
- `click_reservar`
- `click_whatsapp`
- `click_eventos`
- `click_como_chegar`
- `click_cardapio`
- `click_cafe_da_manha`
- `click_almoco`
- `click_idioma`

## Caminho no GA4
1. Admin → Data display → Events.
2. Procurar cada evento da lista.
3. Marcar como key event.
4. Validar no relatório Realtime após clicar em reserva, WhatsApp, cardápio e como chegar.

## Observação
Eventos só aparecem na tela de Events depois de serem recebidos pelo GA4 pelo menos uma vez.
