# Relatórios de auditoria

Os arquivos desta pasta são evidências datadas. Eles registram o estado observado e as decisões tomadas no momento de cada execução; não devem ser interpretados automaticamente como o estado atual do site.

## Fonte de verdade atual

Consulte primeiro:

1. `docs/current-site-status.md` — arquitetura, fatos, métricas e pendências atuais;
2. `README.md` — visão geral do repositório;
3. `CONTRIBUTING.md` — processo de manutenção;
4. `automation_governance_report.md` — workflows autorizados.

## Como ler relatórios antigos

- A data no título ou no cabeçalho define o snapshot.
- Um status `PASS` comprova os critérios daquele relatório, não a perfeição permanente do site.
- Quantidades de páginas, avaliações, seguidores, workflows e URLs podem ter mudado.
- Limitações do GitHub Pages anteriores à migração para Cloudflare Pages estão superadas no domínio público.
- Relatórios de scripts mutantes não autorizam nova execução do script.
- Em caso de conflito factual, prevalece `docs/current-site-status.md` e a confirmação do responsável pelo negócio.
